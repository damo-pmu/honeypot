# Feature 1.2 - Sessions API

## Status ✅ Production Ready

## Description
Endpoints de suivi de session pour chaque interaction attaquant.

## Endpoints

| Méthode | Path | Description |
|---------|------|-------------|
| GET | /sessions | Liste les sessions (max 100) |
| POST | /sessions | Crée une nouvelle session |
| GET | /sessions/{id} | Détail d'une session |

## Modèle de données

```json
{
  "id": 1,
  "attacker_ip": "192.168.1.1",
  "protocol": "ssh",
  "start_time": "2026-05-31T10:00:00",
  "interaction_count": 42,
  "duration_seconds": 1200
}
```
