# Feature 1.3 - Commands Logging

## Status ✅ Production Ready

## Description
Endpoints pour logger et récupérer les commandes exécutées par les attaquant·e·s.

## Endpoints

| Méthode | Path | Description |
|---------|------|-------------|
| GET | /commands | Liste les commandes (max 100) |
| POST | /commands | Log une commande |
| GET | /commands/session/{id} | Commands d'une session |

## Auto-Detection
- Commands flaggués si contiennent: `passwd`, `shadow`, `root`, `sudo`
- Flag `flagged: bool` pour filtrage SOC

## Modèle de données

```json
{
  "id": 3,
  "session_id": 1,
  "command": "cat /etc/passwd",
  "timestamp": "2026-05-31T10:05:00",
  "flagged": true
}
```
