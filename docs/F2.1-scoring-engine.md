## Description
Moteur de scoring rules-based pour classer les menaces.

## Règles par défaut

| Attack Type | Score |
|------------|-------|
| brute_force | 20 |
| sqli_attempt | 30 |
| malware_download | 50 |
| port_scan | 15 |
| reconnaissance | 10 |
| ai_agent_pattern | 25 |

## APIs

| Fonction | Retour |
|----------|--------|
| `calculate_score(type)` | int (0-50) |
| `classify_threat(score)` | str (BOTNET_NODE, etc) |
