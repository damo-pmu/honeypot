# Feature 2.2 - Behavior Classification

## Status ✅ Production Ready

## Description
Classification comportementale basée sur timing et patterns.

## Classification types

| Type | Critère |
|------|---------|
| BOT | Timing constant, pas de variabilité |
| AUTOMATED_SCANNER | Vitesse > 10 req/s, patterns répétés |
| HUMAN_OPERATOR | Latence variable, erreurs, adaptation |
| SCRIPT_KIDDIE | Commandes basiques, pas de stealth |
| BOTNET_NODE | Coordination multi-IP, C2 patterns |
| POSSIBLE_AI_AGENT | Variations inattendues, prompts structurés |

## Méthodes

```python
analyze_timing(interactions: List[float]) -> dict
detect_patterns(commands: List[str]) -> str
calculate_behavior_score(session) -> int
```
