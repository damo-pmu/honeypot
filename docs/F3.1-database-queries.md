# Feature 3.1 - Database Queries

## Status ✅ Production Ready

## Description
Requêtes SQL pré-configurées pour analytics externes.

## Queries disponibles

### `get_top_attackers(limit=10)`
Top IPs par fréquence d'attaque.

### `get_flagged_commands()`
Toutes les commandes suspectes (passwd, shadow, etc).

### `get_attack_timeline(hours=24)`
Timeline horaire des attaques avec score moyen.

## Usage externe

```python
from src.infrastructure.database.queries import get_top_attackers

# Via SQLAlchemy
results = session.execute(text(get_top_attackers(10)))
```
