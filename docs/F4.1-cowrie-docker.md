# Feature 4.1 - Docker/Cowrie Integration

## Status ✅ Production Ready

## Description
Intégration complète Cowrie honeypot via Docker avec worker d'events.

## Architecture

```
┌─────────────┐     ┌──────────┐     ┌──────────┐
│   Cowrie    │────▶│  Worker  │────▶│    API   │
│ (ssh/telnet)│     │(ingest)  │     │          │
└─────────────┘     └──────────┘     └──────────┘
       │                 │
       ▼                 ▼
  cowrie.json       POST /events
```

## Docker Services

| Service | Port | Role |
|---------|------|------|
| api | 8000 | REST API + storage |
| cowrie | 2222/23 | SSH/Telnet honeypot |
| worker | - | Tail logs → API |
| postgres | 5432 | Database |
| redis | 6379 | Cache |

## Launch

```bash
docker-compose up -d
# SSH honeypot ready on port 2222
```
