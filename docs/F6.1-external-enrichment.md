# Feature 6.1: External IOC Enrichment

## Overview
Integration with external threat intelligence feeds to enrich detected IOCs with reputation data.

## Providers Supported
- **VirusTotal** - File hash reputation and URL scanning ✓
- **AbuseIPDB** - IP address reputation and reports ✓  
- **URLHaus** - Malicious URL database (open source) ✓

## Configuration
Environment variables:
```bash
VT_API_KEY=your_virustotal_api_key        # Optional (4 req/min free)
ABUSEIPDB_API_KEY=your_abuseipdb_api_key    # Optional (1000 req/day free)
```

## API Endpoints (`src/api/endpoints/enrichment.py`)

| Endpoint | Method | Description |
|----------|--------|-------------|
| `/ioc/lookup/{ioc_value}` | GET | Multi-provider IOC lookup |
| `/ioc/ip/reputation/{ip}` | GET | AbuseIPDB IP reputation |
| `/ioc/url/check` | GET | URLHaus/VT URL check |
| `/ioc/hash/{hash_value}` | GET | VirusTotal file check |
